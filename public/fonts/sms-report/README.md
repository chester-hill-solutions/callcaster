# SMS report fallback fonts

Unmodified GNU Unifont 18.0.01 fonts from [Unifoundry](https://www.unifoundry.com/unifont/index.html):

- `unifont-18.0.01.otf`: printable Basic Multilingual Plane characters.
- `unifont_upper-18.0.01.otf`: supplementary characters, including monochrome emoji.

The font files retain their embedded copyright notices. See `OFL-1.1.txt` for the redistribution license. The report uses the existing Sarabun fonts for Latin and Thai text and uses Unifont as a fallback. Unifont displays complex-script characters but does not provide all contextual letter forms or emoji sequences. The PDF also preserves original text in ActualText; Markdown and CSV contain the original reply bytes.
