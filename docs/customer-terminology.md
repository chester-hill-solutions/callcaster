# Customer terminology

CallCaster uses **Automated phone menu** as the customer-facing name for the
machine-dialled phone-menu product. Use this wording in campaign setup,
onboarding, pricing, billing, and launch copy.

Use **IVR** when describing the technical implementation, such as script
builders, runtime behavior, API fields, worker logs, or billing code. Keep
internal values such as `robocall`, `simple_ivr`, and `complex_ivr` unchanged.

Use **Robocalls** only when a marketing surface describes the separate
voice-broadcast service. It is not the customer-facing name for the automated
phone-menu campaign goal.
